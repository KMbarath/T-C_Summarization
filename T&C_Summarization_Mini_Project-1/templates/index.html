How It Works

01

OCR Extraction

Tesseract OCR converts image screenshots of legal documents into raw machine-readable text.

02

NLP Summarization

NLTK scores every sentence using word-frequency analysis with a legal-domain keyword boost.

03

Clause Tagging

Each sentence is classified into a legal category — Privacy, Payment, Liability, and more.

04

Translation

Google Translate API (via deep-translator) converts the summary into 25+ languages instantly.

05

Voice Readout

gTTS converts the translated summary to natural speech — in the selected language — playable right in the browser.
